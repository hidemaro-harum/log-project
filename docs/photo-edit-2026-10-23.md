# BiteLog 写真編集・並べ替え（2026-10-23）

写真の登録時に、向き・比率・順番を調整できるようにした。既存の未コミット変更を引き継ぎ、今回の対象は写真まわりに限定している。

2026-10-24追記: 以下は写真編集を実装した時点の記録。後続の保存処理の修正、依存更新、RLS反映とリリース状態は[コードレビュー・リリース記録](review-release-2026-10-24.md)を参照。

## 使い方

1. 「今日の一皿を記録」「店舗を追加・編集」「訪問記録を追加」で写真を選ぶ。選択後も写真を追加できる。
2. 各写真の「編集」から左右90度回転、元の比率・正方形・縦長3:4・横長4:3、拡大、切り抜き位置を調整する。
3. プレビューを見て「編集を適用」を押す。「元の写真に戻す」で登録前の原本に戻せる。キャンセルした変更は反映されない。
4. 「前へ・後ろへ」またはドラッグで順番を調整する。新規店舗では先頭が表紙になる。既存店舗への追加では、選択した写真は登録済み写真の後ろに追加される。
5. 登録後は店舗詳細で、同じく前後ボタン・ドラッグ・「表紙にする」で並べ替える。

回転・切り抜きは今回選択した写真が対象。登録済み写真を再加工する機能は今回の対象外。

## 実装

- `src/components/bitelog/photo-picker.tsx`: 追加選択、プレビュー、選択解除、順番変更、表紙指定、原本と編集設定の保持。
- `src/components/bitelog/photo-editor.tsx`: 編集ダイアログ。プレビューと出力は共通の描画処理を使う。フォーカス復帰、Esc、適用中に閉じた場合の処理、画像URL解放にも対応。
- `src/lib/photo-edit.ts`: 回転後の座標で比率・拡大率・切り抜き位置を計算し、最大2048pxのPNGへ描画。登録時は既存処理でWebPへ圧縮する。
- `src/lib/photo-edit.test.ts`: 回転、切り抜き、端の位置、不正値、描画変換・出力サイズの検証。
- `src/app/page.tsx`: 各フォームと編集部品を接続。EXIFの日付・位置情報は編集前の原本から取得し、写真削除時は古い非同期結果を破棄する。画像処理を店舗・訪問の保存より先に実行する。
- 店舗詳細の並べ替え: 44pxの操作ボタン、写真全体の表示、保存中の操作制御、通信失敗時の復元、ドラッグ中断時の取消。

DBスキーマ、Storage設定、認証設定、依存パッケージは変更していない。
