# iPhoneで写真追加画面の本文が消える症状への対応

ユーザーの実機画像では「写真を追加」の見出し・店名・閉じるボタンだけが表示され、フォーム全体が見えていなかった。前回は写真選択inputの起動を中心に確認し、このレイアウトの失敗を捉えられていなかった。

写真追加ダイアログは高さauto・max-heightのみのflexコンテナ、その中のフォームはflex:1・min-height:0、外側はoverflow:hiddenだった。Safariの内容サイズ計算でフォームが縮む可能性を除くため、通常のblock配置とダイアログ全体の縦スクロールへ変更。保存ボタンも通常の流れに置き、狭い画面で入力欄に重ならないようにした。保存処理は変更していない。

PlaywrightのWebKit（iPhone 15相当）で393×852、320×568、852×393を確認。フォームの実高さは607px、717.5px、518pxで、写真選択inputの中心にタップが届くことを確認した。写真1枚の選択・モック保存・追加表示と、12枚選択時の保存ボタンまでのスクロールを確認した。タップによるfilechooser起動も確認済み。

実機iPhoneでの再現・解消は未確認。前回と同じ見逃しを防ぐため、今後はchooser起動だけでなく、フォーム実寸・タップ位置の遮蔽・長いフォームのスクロール・保存完了を確認する。今回の検証コードと結果は `output/photo-layout-2026-10-31/` に保存。

lintと差分の空白チェックは成功。ビルド・本番反映結果は完了後に追記する。
