# BiteLog 店舗詳細からの写真追加（2026-10-23）

登録済み店舗の詳細に「写真を追加」を設け、訪問記録を増やさず複数の写真を追加できるようにした。「行きたい」店舗でも、状態や訪問履歴を変えずに利用できる。

2026-10-24追記: 以下は写真追加を実装した時点の記録。保存・モーダル処理の共通化、店舗・訪問登録フォームへの再試行対応、依存更新、RLS反映とリリース状態は[コードレビュー・リリース記録](review-release-2026-10-24.md)を参照。

## 使い方

1. 店舗詳細の写真欄で「写真を追加」を押す。
2. 写真を複数選び、既存の写真選択・編集部品で回転、切り抜き、順番を調整する。追加選択や選択解除もできる。
3. 必要なら「写真のメモ（任意）」を入力する。メモは今回選んだ写真すべてに付く。
4. 「写真を追加する」を押す。既存写真の後ろへ、選択した順番で追加される。

一部の保存に失敗した場合、保存を確認できた写真を選択一覧から外し、残りだけを再送する。通信が途切れて保存結果を確認できない場合は、写真の選択・編集・順番・メモを固定し、同じ内容で再試行できる。ダイアログは閉じられるが、閉じると未完了の選択は保持されない。

## 実装

- `src/components/bitelog/photo-add-dialog.tsx`: 複数選択、編集、共通メモ、保存中の操作制御、部分失敗後の再送。写真編集のEscでは追加ダイアログを閉じない。
- `src/lib/restaurant-photo-add.ts`: 全画像のWebP変換が成功してから書き込む。`visit_id: null` を指定し、選択時のIDを写真IDと保存パスに再利用する。Storageは同じパス、DBは同じIDでupsertし、結果が不明な保存を再試行しても写真を重複作成しない。
- `src/lib/restaurant-photo-add.test.ts`: 画像準備の先行、訪問なしの追加順、最初の失敗での中断、保存結果が不明な場合の再試行と編集固定フラグを検証。
- `src/app/page.tsx`: 店舗詳細への入口と、追加を確認できた写真の表示を接続。

DBスキーマ、Storage設定、認証・権限設定、依存パッケージは変更していない。
