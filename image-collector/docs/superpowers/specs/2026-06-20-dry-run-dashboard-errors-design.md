# ドライランのエラー詳細表示

## 目的

画像集約のドライランでエラー件数だけでなく、修正対象となるmaster行と原因を`dashboard`シートで確認できるようにする。

## 仕様

- ドライラン開始時に`dashboard`シートを初期化し、以前の内容を今回の結果で置き換える。
- 上部のサマリーには処理件数、コピー予定数、重複スキップ数、その他スキップ数、エラー数を表示する。
- エラーになったmaster行について、行番号、管理番号、フォルダURL、エラー原因を明細へ記録する。
- 管理番号またはフォルダリンクが空の行は、従来どおりその他スキップとして集計する。
- 完了ダイアログには従来どおり集計結果を表示する。
- ドライランでは画像コピー、メール通知、進捗保存、自動再開トリガーを実行しない。

## 実装方針

- 既存の`dashboard`初期化・サマリー更新処理をドライランでも利用する。
- 明細にフォルダURLを格納できるよう、ダッシュボード列を追加する。
- ソースフォルダのURL解析・アクセス失敗時に、例外メッセージと対象URLを記録する。
- ドライラン中はコピー処理の代わりに既存の件数シミュレーションを維持する。

## テスト

- ドライランのフォルダアクセスエラーがdashboard明細へ記録されること。
- ドライランでdashboardサマリーが更新されること。
- ドライランで`makeCopy`が呼ばれないこと。
- 本実行の既存挙動が変わらないこと。
